# TBSI 下一阶段项目说明书：MACA + RTM

> 更新日期：2026-07-31
> 当前状态：HPF-TVR 已停止；新方向进入最小可行性验证。
> 主评测：LasHeR test，244 条序列。
> 可信基线：TBSI ep0015，AUC 55.46。

## 1. 路线裁决

HPF-TVR 的 Gate 1 已停止推进。全量结果如下：

| 方案 | AUC | 相对基线 | 结论 |
|---|---:|---:|---|
| TBSI ep0015 | 55.46 | 0.00 | incumbent |
| HPF-TVR rho=0.05 | 55.18 | -0.28 | CI 跨 0，停止 |
| HPF-TVR rho=0.10 | 55.35 | -0.10 | CI 跨 0，停止 |
| phase-1 oracle | 56.43 | +0.97 | 仅说明理论上限 |

停止原因不是候选幅度没有调好，而是候选空间的全量收益不稳定、正增益高度集中，且 learnable router 无法从单帧信息恢复 oracle。后续不再使用候选动作、oracle 路由、rollout verifier 或选择性干预作为主线。

## 2. 全实验复盘后的新问题定义

过去 166 个实验主要反复修改“融合结果本身”：门控、残差、频域校准、信号解耦和时序 token 都把不确定信息直接注入 TBSI 特征。全量结果表明：

1. RGB/TIR 差异和频域冲突是相关性信号，不是足以支持逐帧干预的充分条件。
2. 小模块直接修改融合特征会产生正常帧负迁移；zero-init 和弱尺度只能减少破坏，不能产生可靠收益。
3. Temporal Token 没有形成稳定短期记忆；TBSI 的首帧模板提供长期外观锚点，但缺少安全的近期目标状态。
4. mini 数据集上的局部收益不能代表全量序列稳定性。

新问题定义为：

> 在保留 TBSI 主干行为的前提下，分别解决跨模态表示偏移和短期目标状态过时问题。

## 3. 新方法总览

```text
RGB / TIR search
        |
        v
Frozen TBSI backbone and original fusion
        |
        +--> MACA: modality-anchor consistency adapter
        |       align RGB/TIR evidence to fused anchor
        |
        +--> RTM: restricted target memory
                initial slot + one recent slot
                confidence/smoothness controlled update
        |
        v
Original CenterPredictor
```

两项创新分别承担不同职责：

- MACA 改善“输入表示是否处于可融合坐标系”；
- RTM 改善“当前目标表示是否仍代表近期外观”。

不再让一个路由器同时猜模态质量、修改特征并承担时序决策。

## 4. 创新点一：MACA

### 4.1 名称

**MACA：Modality-Anchor Consistency Adapter，模态锚点一致性适配器。**

### 4.2 核心思想

TBSI 已经完成强交互融合，新的模块不再输出 RGB/TIR 权重，也不生成候选特征。MACA 只学习一个接近恒等映射的轻量适配：使用 RGB、TIR 和原始融合特征的局部统计，生成低秩的通道仿射参数，把两路模态证据对齐到 TBSI 融合锚点。

设 `F_b` 为原始 TBSI fused feature，`F_r`、`F_i` 为保留的模态证据：

```text
z_m = LN(F_m)
a_m, b_m = LowRankAdapter(pool(z_m, LN(F_b)))
F_m' = (1 + clip(a_m)) * z_m + b_m
F_out = TBSI_fused(F_r', F_i')
```

首版要求：

- adapter 零初始化或恒等初始化；
- 参数规模控制在 0.1% 级别；
- 不预测可靠性分数，不产生 hard/soft 模态选择；
- 仅插入已有 fusion interface，不改 TBSI attention 拓扑。

### 4.3 训练约束

- 模态 dropout：随机弱化一路输入，避免 adapter 依赖固定模态；
- anchor consistency：完整模态与单模态扰动的融合表示保持局部一致；
- local reconstruction：适配后的表示不能偏离原始 TBSI 表示过远；
- 主跟踪损失：最终仍由 box/head 任务损失决定方向。

这不是旧式 residual gate 的重复：MACA 不学习“是否应该使用 RGB/TIR”，而学习两个模态如何在进入 TBSI 交互前保持统计可比较，同时用重建约束保护基线。

## 5. 创新点二：RTM

### 5.1 名称

**RTM：Restricted Target Memory，受限目标记忆。**

### 5.2 核心思想

TBSI 的首帧模板保留为永久锚点，不直接更新。RTM 在外部增加两个目标 prototype 槽位：

```text
M0: first-frame stable prototype, never replaced
M1: one recent prototype, conservatively updated
```

当前搜索特征经过目标区域 ROI pooling 得到 `q_t`。只有当以下信号同时满足时，才更新 `M1`：

- response peak 高且熵低；
- 当前框与历史框的运动/尺度变化不过大；
- `q_t` 与 `M0/M1` 的相似度没有明显冲突。

记更新门为 `g_t`，读出为：

```text
M_t = (1 - g_t) * M1 + g_t * q_t
F_head = FiLM(F_b; M_t)
```

首版只允许一个 recent slot，避免无界 memory bank 引入冗余和污染。RTM 只调制 head 输入，不替换 TBSI template，不触发额外 backbone 前向，也不使用测试时反向传播。

### 5.3 时序逻辑

RTM 的时序不是新增 token，而是一个受约束的状态更新系统：

```text
当前预测 -> 置信度/平滑性检查 -> 允许更新 recent memory
       \-> 不可信 -> 保留旧 memory 和首帧锚点
```

它直接对应复盘中的结构性缺口：首帧模板负责长期身份，recent slot 负责短期外观变化，更新门负责防止错误自训练。

## 6. 为什么选择这两个迁移方向

这两个组件分别来自相邻视觉领域，而不是把 RGB-T 跟踪论文中的模块重新拼接：

- 参数高效 adapter / cross-modal adapter：用于低参数跨模态迁移和共享锚点保持；
- 受限 memory bank：RMem（CVPR 2024）证明有限而非无限历史更易解码；
- distractor-aware memory：DAM4SAM（CVPR 2025）强调记忆更新需要识别干扰物；
- latest object memory：LOMM（ICCV 2025）强调显式维护近期目标状态。

迁移后的新意不在于简单调用现成模块，而在于把它们放到 TBSI 的两个互补边界：MACA 负责融合前后的表示稳定，RTM 负责融合后的目标状态稳定。

## 7. 最小实验顺序

所有实验从可信 ep0015 checkpoint 开始，先冻结 TBSI 主干。

1. **RTM-only**：冻结 TBSI，加入固定门控的 recent memory，优先验证长序列收益和污染率。
2. **MACA-only**：只训练 MACA，验证跨模态对齐是否能在全量上带来正增益。
3. **MACA + RTM**：仅当前两者至少一个在全量上不低于基线时才运行。
4. **小规模联合微调**：只解冻 MACA、RTM 与 head 的最后轻量接口，不解冻 TBSI backbone。

报告：AUC、OP50、OP75、Precision、Norm Precision、逐序列 bootstrap、短/长序列分组、RTM 更新率、拒绝更新率和 memory 相似度分布。

## 8. 止损标准

- MACA-only 全量低于基线：停止 adapter 族，不再换激活函数或增加秩。
- RTM-only 长序列下降：停止 memory 族，不增加槽位，只检查更新门设计。
- 联合模型未达到 `+0.30 AUC`：停止外部融合增强，不再叠加第三个模块。
- 任何只在 mini 或单一属性上涨的结果：记为分析证据，不作为路线晋级。

## 9. 代码落点

- MACA：`TBSI/lib/models/tbsi_track/tbsi_track.py` 的 fusion interface，优先放在原始 `get_fusion_pack` 输出到 head 的边界；不修改 TBSI attention 结构。
- RTM：`TBSI/lib/test/tracker/tbsi_track.py` 的 tracker state 与 `TBSI/lib/models/tbsi_track/tbsi_track.py` 的 head 输入接口；首版只维护 prototype，不维护候选框集合。
- 配置：新增独立 `MACA_*`、`RTM_*` 开关，默认关闭，保证 baseline 路径完全不变。

## 10. 当前论文定位

暂定题目：

**Anchor-Calibrated Fusion with Restricted Target Memory for RGB-T Tracking**

论文的两个核心贡献：

1. 用模态锚点一致性 adapter 进行参数高效的 RGB/TIR 表示校准，并通过局部重建约束保护强基线；
2. 用受限双槽目标记忆补充首帧模板的短期外观缺失，并通过置信度与运动一致性控制在线更新。

旧 HPF-TVR、CUTR、router、频域门控和 temporal token 结果统一作为负面证据：它们说明直接预测“何时修改融合结果”不稳定，而新方法改为稳定表示与稳定状态两个可分解问题。
