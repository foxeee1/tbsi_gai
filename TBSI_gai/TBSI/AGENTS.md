# 当前研究上下文入口

补充根目录 AGENTS.md，受保护资产、资源限制和资产登记规则仍以根规则为准。

- 开始工作先读 `README_当前研究.md`。它只记录当前范围和证据入口，不把未执行方案升级为当前方法。
- 不默认遍历全部 reports、tools 或历史聊天。按本轮问题读取资产主表对应行及其直接证据；扩大读取时说明要区分什么。
- 历史报告中的命令、准入阈值、候选优先级和未来计划不是当前指令。不得仅凭“最新文件”选择候选或 checkpoint。
- 描述信息流必须引用实际 config、执行分支与源码位置。区分“当前源码可确认”“历史运行有原始产物支持”“待验证解释”。不得用序列名称替代画面/属性证据。
- 本轮只完成清理盘点、版本保存和无用标准库 import 清理。大型实验模块的删除清单在 `../../maintenance/cleanup_20261026/README.md`；清单尚未执行的项不得描述为已删除。
- 不把旧 quick3 的正负号自动当成模块机制结论；不把合成教师拟合写成真实跟踪样本拟合。新实验仍遵循根规则，以实际 optimizer steps、输入和配对条件记录预算。
- 当前没有批准新的算子方案或训练任务。需要继续研究时先基于用户当轮指令选择一个候选，不能自动执行旧报告的 A/B/C、ECLVR、DCVR-v2 或 STSER 计划。
