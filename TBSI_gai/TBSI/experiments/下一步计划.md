# M1 / DCVR-v2 后续优化计划（2026-10-26）

## 目标与当前判断

以论文草稿 `experiments/reports/dcvr_manuscript_draft_20261026.tex` 中的 DCVR-v2 为唯一待验证方法线：保留原生 MSHA 的 QK 匹配、同模态消息、CENTER 解码和模板状态更新，只对模板来源的跨模态 Value 消息做前景条件路由。研究目标是验证“目标前景与当前匹配证据能否更好地分配跨模态消息”，而不是把路由权重变化本身当成收益。

目前可以信任的观察是：DCVR-v1 的 Value 路径确实发生了重分配；其固定状态定位收益未得到支持，full-244 点估计低于 M1 登记值，且训练未收到前景 mask、测试使用了真实 mask。M1 当前结果目录重算值与受保护 M1 日志不一致，因此历史序列配对不能作为正式因果差值。另一个同 seed、同 quick3 数据轨迹的 Early-gate control 重复，quick7 AUC 相差 11.15 pp；1,664 条样本的序列/帧采样记录相同，但增强后 tensor 尚未核对。这个控制重复性问题必须先于短训候选排名处理。

计划结论：**保留 DCVR-v2 作为候选研究线，暂不进入新算子训练。先验证训练输入重复性、DCVR 前景 mask 合同和跨模态路径隔离，再评估路由证据与定位效用是否对齐。**

## 实施约束与判断规则

1. 现有 DCVR-v1 quick3 正向差值由单一序列主导，且训练使用 uniform fallback、测试用真实 mask；不能作为 DCVR-v2 通过或不通过的性能证据。
2. Early-gate quick3 control 重复显示同一采样轨迹不足以确保同一增强输入或同一闭环输出。P1 先解决 post-augmentation 输入是否一致；输入一致后，短训候选的判定仍需与 control-repeat 波动比较。
3. 论文中的 token 权重虽经前景均值归一，但最终 `b_{m→n}\hat g_i` 的有效缩放峰值尚无实测边界。P2 必须记录 token 极值和分位数；若有尖峰，再另立单变量“有界 token 残差”候选，不与 mask 修复或新信号同时改。
4. DCVR-v2 的方向与 token 两个尺度是论文主方法定义，但实验归因必须保留独立开关/消融，避免只知道组合变化、不知道来源。
5. quick3 仅为筛查。旧 quick7 manifest 是从结果目录回建的，不是预注册 holdout；不能单独用于候选晋级或论文主结果。
6. M1 是受保护 parent。引用固定指标时使用资产数据库记录；不能用当前 M1 预测目录重算值替换它，也不能覆盖 M1 配置或输出。
7. 本计划不授权删除资产或启动训练/测试。当前剩余空间约 1.1 GB，需先核实可用输出盘或已登记废弃文件清单。
