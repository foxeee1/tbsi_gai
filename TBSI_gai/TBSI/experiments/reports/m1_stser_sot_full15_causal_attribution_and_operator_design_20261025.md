# STSER full15 掉点归因与目标条件模板消息重分配设计

日期：2026-10-25。对象：`M1_STSER_SOT_FULL15_COMPETITION_20261025`。研究锚点：受保护 M1 `TBSI_E_MHSA_FULL_4090D_seed42`。本报告写作时只读取代码、配置、已有日志、CPU checkpoint、预测框和标注，完成离线统计；**没有训练、tracker 推理、模型 forward、合同测试或新模型实现**。后续的脚本准备状态见文末补记，不能把脚本存在误读为实验已通过。

## 1. 独立判断与证据边界

本组确实没有达到提升目标：LasHeR full-244 AUC 为 55.9822，较 M1 固定参考 56.21 低约 0.23 个百分点。但“已观察到点估计下降”不等于“已经确定下降的唯一原因”。当前最有根据的诊断是：**竞争信息的语义不够准确，而且它到输出的专有通道被近确定性的专家路由压缩；新增结构并没有明确实现目标身份条件下的竞争内容重构。**

支持这一诊断的最强证据，是代码中的依赖关系和训练第 2 epoch 后的路由饱和，不是负 gamma、全局特征改变量小，或有没有非零梯度。完整解释 -0.23 还缺少同初始化的结构消融、有效 M1 配对轨迹和独立 seed；本报告不把这些缺失项补写为结论。

| 结论 | 证据等级 | 当前判断 |
|---|---|---|
| 五项全量指标小幅低于 M1 固定参考 | 已有完整候选结果 + M1 登记 aggregate | 已观察；单 seed，不能称稳健退化 |
| 本组从错误的 M1 epoch15 权重开始 | 本组配置、provenance、SOT state 审计 | 已排除；这是另一组历史续训的混杂，不适用于本组 |
| 分支整体断图 / 没进入 optimizer | 参数分组、专项梯度、checkpoint optimizer state | 不支持整体断图；不能据此声称每个参数每一步均得到有效学习 |
| 训练中的专家选择退化为近固定模态策略 | 270 个采样 batch，逐 epoch 路由统计 | 已观察；尚无测试帧逐 token 路由日志 |
| 非邻域 search-search 相似位置是真实干扰物 | 当前 competitor 定义不使用模板目标身份 | 未建立；有可能选中同一目标的其他部位 |

| 当前全部失败均来自融合 / CENTER | 仅有预测几何和当前诊断 | 尚未区分；不能作为首因写入论文 |

### 2.1 实际训练进度

名义 15×3,744/8=7,020 次 optimizer 更新机会；checkpoint 中有 state 的 263 个参数 tensor 的 Adam step 均为 **7,016**。相差4次，AMP 跳过更新是一种合理解释，但缺少 scaler 轨迹，不能定论；该差异约0.057%，不能据此解释全部掉点。剩余2个 optimizer 参数 tensor 无 state，本轮未建立其精确参数身份，不能用它们指认 STSER 断图。

### 2.2 仍存在的初始化配对风险

SOT state 中没有原生 `v2_template_fusion` 或 STSER 参数；本组有18个原生融合 state 条目需要新初始化。新增模块的构造及递归初始化会消耗 RNG，因此同 seed 并不自动保证两种结构的公共新参数初值逐 tensor 相同。代码只对 PVL 显式隔离了初始化 RNG，本组没有相同保证。**这是静态风险，不是本轮已经测得的公共初值差异。**后续应保存、复用公共初始 state 及其逐 tensor hash，而不是因此把本组再次判为错误的 SOT 训练合同。

## 3. 实际信息流：需要先纠正的研究前提

实际前向为：

```text
首帧 RGB/TIR 模板 + 当前 RGB/TIR 搜索图
  → 每模态拼接 64 template + 256 search tokens
  → 普通 ViT block：每模态完整 320-token 自注意力
  → block index 3 / 6 / 9 的模板联合 MSHA
       原生融合：RGB/TIR template token 共同交互；search 在该融合支路不直接写回
  → 仅 block index 9 增加 STSER
       RGB search 读取融合后的 TIR template；TIR 反向读取 RGB template
       → 同一个跨模态 T2S message
       → shared/private/zero 专家混合
       → output projection → 先限幅，再乘 gamma → search 残差
  → 后续 ViT blocks 10、11 → final LayerNorm → 原 CENTER head → bbox → 下一帧 crop
```

源文件：`vit_tbsi_care.py:49–109, 363–387, 417–480`；`tbsi_layer.py:1387–1450, 1522–1558`。

因此必须区分：

1. MSHA 的模板特征交互，与在线更新首帧模板图像/记忆，不是一件事；本组没有开启后者。
2. M1 的模板在普通 ViT block 中已经隐式接收当前搜索上下文，不能写成“完全无条件模板”。
3. STSER 是原生模板 MSHA **之后新增的 search-side 模板消息传输支路**，不能描述为已在 MSHA 内部修复了某个已证实缺陷。
4. `m1_related_open_source_audit_20261024.md` 中把 M1 原生 MSHA 画成 search-query 256×64 T2S 的部分与实际代码不符；后续论文图以本节代码审计为准。

更准确的研究问题是：**已有隐式交互和跨模态模板融合，是否仍缺少对“模板证据在不同搜索候选间的区分度”的显式建模？**这是待验证的算子级假设，尚不是 M1 的已证实首因。

## 5. 算子级归因

### 5.1 最强证据：竞争输入的专有作用通道早期接近饱和

当前形式为：

\[
c_i=\operatorname{TopKPool}_{k\notin3\times3(i)}\cos(x_i,x_k),\qquad
p_i=\operatorname{softmax}(R([x_i,m_i,x_i-c_i,a_i])/0.07),
\]
\[
r_i=p_i^s E_s(m_i)+p_i^p E_p(m_i)+p_i^0\cdot0.
\]

`c_i` 的实际内容为加权 search 特征，第一式用 TopKPool 简写这一过程。两个非零专家接收相同 `m_i`；`x_i-c_i` 仅通过 `p_i` 影响输出。shared 是参数共享，private 是模态各用一套参数，**不是已经学得共享/私有语义解耦的证明**。

逐 epoch 均值：

| epoch | RGB shared | TIR private | RGB 相对写回 | TIR 相对写回 | RGB 路由熵上界 | TIR 路由熵上界 |
|---|---:|---:|---:|---:|---:|---:|
| 1 | 0.500982 | 0.482155 | 9.71e-6 | 8.31e-6 | 0.88455 | 0.49759 |
| 2 | 0.999989 | 0.997611 | 3.51e-5 | 9.13e-6 | 0.000132 | 0.015192 |
| 5 | 0.999996 | 0.969343 | 1.19e-5 | 4.33e-5 | 0.000047 | 0.130899 |
| 7 | 0.999987 | 0.999991 | 4.43e-6 | 1.11e-4 | 0.000152 | 0.000111 |
| 15 | 0.999973 | 0.999999 | 4.54e-5 | 1.39e-3 | 0.000324 | 0.000013 |

每 epoch 18 个采样 batch，合计270个；epoch2–15的252个 RGB 采样 batch 全部 shared≥0.999。TIR private≥0.99为237/270，≥0.999为202/270。

日志给的是 token/batch 概率均值，表内熵是各 batch 的 `H(mean p)` 再求均值，是平均逐 token 熵的**上界**。虽然没有直接逐 token 熵，接近1的均值仍能支持大多数采样 token 使用同一专家。

设 `p=softmax(l/τ)`，则

\[
\frac{\partial p}{\partial l}=\frac{\operatorname{diag}(p)-pp^\top}{\tau}.
\]

由均值和 Jensen 不等式可得平均 Jacobian trace 上界：`(1−||mean p||²)/τ`。epoch15 RGB/TIR 的该上界均值分别约 `7.84e-4 / 2.55e-5`；均匀3路时为9.52。**这只是 softmax 这个环节的敏感度上界，不能当作整个网络对 competitor 的梯度或因果效应。**但它明确说明竞争信息只靠这道门进入输出，通道已很受限。

router 输入没有规范化，且检索 top-k 与3类路由复用0.07温度；较小 logit 差就能得到极端概率。这是饱和的合理机制解释，但尚未通过单变量温度/规范化干预验证。固定专家策略也可能有用，因此“饱和存在”不等于“解除饱和一定涨点”。

### 5.2 语义错位：相似 search token 不是已确认负样本

当前 competitor 与模板目标身份无关，只在同模态 search 内找非邻域相似位置。3×3之外仍可能是同一目标的其他部位；背景纹理的高相似位置也可能没有目标竞争关系。对每个 token 都称其为 hard negative，比实际代码能支持的语义更强。

因此短训中“加竞争描述后 routing 改变”只能说明网络使用了额外输入，不能证明它学会了模板目标与干扰候选的区分。

### 5.3 内容路径不足：竞争证据没有直接决定传什么

两个专家都是 `E(m)`，没有把竞争位置的模板支持结构写入消息，也没有保证相同的模板片段在不同候选间被区别利用。当 route 近固定时，该分支主要表现为每模态固定变换后的 T2S 残差。它仍是输入相关的 attention，不是整体变成常数；失去的主要是**竞争描述所负责的额外条件决策**。

这比笼统说“CENTER 不传导”更接近可修改的实际接口。CENTER 仍可能放大误差，但当前没有 head 损坏证据，主干和损失也已有训练能力，不以改 head 作为本轮主方案。

### 5.4 不能当作掉点证据的量

- **负 gamma**：checkpoint 最终为 RGB `0.0025316102`、TIR `-0.0180810429`。output projection 可吸收符号，负值不是有害抑制或失效的证明。
- **小的全局相对写回**：末次日志约 `5.31e-5/1.41e-3`，可能在少数目标 token、后续 block 或闭环中被放大，不能证明未作用到决策，也不能据此直接放大残差。
- **“有界 gamma”**：实际先把 residual 限制为输入 token 范数的10%，再乘无界可学习 gamma；当前实现没有给 gamma 自身设界。
- **全模型梯度范数0.1**：日志在 AMP unscale 和全局 clipping 之后记录，缺少 preclip norm/clip factor，不能由恒定0.1推出裁剪是主因。
- **“所有 tensor 总是非零梯度”**：采样中 router 非零 tensor 最少4/8、experts最少12/18、attention最少6/8。梯度还被四舍五入到8位，不能把显示0或任意非零等同于完全死亡或机制成功。
- **特征范数单位**：input norm 是整个 tensor 的范数，message norm 是逐 token 范数均值，不能直接用约7,800对约60判定二者失衡。
- `feature_changes.csv` 的 `rgb_prob_mean/tir_prob_mean=0` 是 STSER 缺少相应键时的占位，不能称 route 概率为0。`internal_signals.csv` 存在表头/行列数不一致，未用于精确层归因。

## 6. 为什么 quick3 正信号与 full15 无提升可以同时出现

SOT quick3 的 +0.670 AUC 来自 **STSER 无 competition 的 control**，其配置 mode=`stser`，不是 mode=`plain_t2s`，更不是直接相对 M1。数据为RPP176 train/60 test、3 epoch、237次名义更新；full15名义更新量约为其29.6倍。

quick3 的 paired AUC CI 为[+0.020,+1.491]，OP75 CI跨零；前三条序列贡献约79%净增益，初步信号有明显异质性。其 TIR private 均值约0.729，full15从epoch2开始就大多近单专家；**训练成熟后条件选择方式变化**是值得检验的解释。但没有早期 full-data checkpoint 的同口径测试，不能说已经证明“早期涨点被后期过拟合吃掉”。quick3 两结构还未保存公共新参数的完全一致初始 state，初始 RNG 差异是剩余混杂。

因此旧 proxy 不足以证明竞争机制有效，当前 full15 也没有在相同训练进度、相同 control 下反驳该 +0.670。正确表述是：**当前 full15 组合暂不支持对 M1 的提升；竞争描述的独立贡献尚未区分。**

新增参数5,319,240，其中 Q/K/V 为3,538,944、output为1,179,648，合计约88.7%；experts302,016、routers295,558、null3,072、gamma2。没有证据表明主要问题是“模块太小、再加专家宽度才有容量”。容量主要花在了全维投影；应先让新增信息作用到正确变量。

## 7. 首选优化：在 STSER 内做目标条件的模板消息重分配

### 7.1 一句话动机和作用位置

**某个模板片段在这里相似，还不足以说明它有辨识力；应同时考虑它在其他位置是否也普遍相似，再让这一相对证据直接改变该位置接收的模板内容。**

保留原生 MSHA 和现有 STSER 的主干接口；在现有 STSER 的专家输出内部增加一条模板来源分布差值修正，进入同一个 output projection/residual。它不是额外换一套融合骨架，也不同时加入时序模板更新、CENTER修改或新排序损失。

这里“内容改变”指不同模板 Value 的混合组成发生变化；**不会直接改写模板 Value 向量本身，也不会直接修改 MSHA 的模板输出**。若论文坚持“MSHA内部无条件模板更新修复”的定位，本方案与该措辞不匹配，应调整题目和方法定位。

### 7.2 模板目标身份锚定

首帧框给出第j个模板 patch 的覆盖权重 `w_j∈[0,1]`，采用 `w̃_j=ε+(1−ε)w_j`，保留少量上下文，避免硬切框。代码已有 `template_box_to_token_weights`，可复用。

训练用该训练样本的 template annotation，推理用首帧 init bbox；当前 search GT 仅用于离线评价/原训练损失，**不进入新算子**。现有 STSER forward 没有接收 mask，actor 的启用条件也未涵盖 STSER；若将来实现，必须显式接通 mask，从 actor/tracker 经 backbone、TBSILayer 进入新分支，不能假定有辅助函数就已使用目标身份。

### 7.3 同一模板片段在不同搜索位置的相对支持

以 RGB search 读取融合 TIR template 为例，复用原 Q/K/V 投影，逐 head 记：

\[
S_{ij}=\frac{\langle\operatorname{normalize}(Q_i),\operatorname{normalize}(K_j)\rangle}{\tau_m},
\quad Q_i=W_q x_i,\quad K_j=W_k z_j,\quad V_j=W_v z_j.
\]

`τ_m` 只用于新匹配描述，不再与3类 router 温度共用配置。初版设计固定 `τ_m=0.2`，是待验证的数值起点，不是已证实最优值；不同时修改旧 router。

对每个搜索位置i和模板片段j，比较“这里的匹配”与“非邻域其他位置对同一片段的匹配”：

\[
b_{ij}=\log\left(\frac1{|\mathcal C(i)|}\sum_{k\in\mathcal C(i)} e^{S_{kj}}\right),
\quad d_{ij}=\tanh\left(\frac{S_{ij}-b_{ij}}{\tau_d}\right),\quad \tau_d=1.
\]

`C(i)` 是候选参考集合，不称为已确认负样本。它从搜索位置中排除以i为中心的目标尺度邻域；尺度先验由模板框长宽比r与固定search factor f=4给出：16×16网格可取 `r_x=ceil(16√r/f)`、`r_y=ceil(16/(f√r))`，排除 `|dx|≤r_x, |dy|≤r_y`。训练和推理用同一模板几何规则，不使用 search GT，也不引入训练时不存在的上一帧 oracle state。

这比固定3×3更有机会避免把同一目标的其他部位当竞争项，但只是几何先验：形变/尺度突变仍可能误分。同一算子的后续消融应比较固定3×3与该邻域，不能把邻域收益隐含归给内容修正。集合为空时返回零修正。

### 7.4 让证据直接改变 Value 来源组成

定义目标模板来源的普通分配与竞争修正分配：

\[
A^0_{ij}=\operatorname{softmax}_{j}(S_{ij}+\log\widetilde w_j),
\quad A^c_{ij}=\operatorname{softmax}_{j}(S_{ij}+\log\widetilde w_j+\lambda\,d_{ij}),
\]
\[
\delta m_i=\sum_j(A^c_{ij}-A^0_{ij})V_j.
\]

每模态一个 `λ∈[0,1]`，例如参数化为 sigmoid，初始化0.1；`ε=0.05`作为首版固定上下文底值。均是待验证设计值，不展开多参数穷举。

`Σ_j(Ac−A0)=0`，因此这条修正具有“重新分配来源”的约束；若所有 Value 完全相同，修正为0。它不能仅凭数学形式保证输出方向改变，Value 近共线时可能仍近似幅度变化，需用实测方向/可分性验证。`λ=0`时修正严格为0。

保留原 T2S message（包括其历史 learnable null）、原专家输出 `r_i^old` 和原 null 路由概率 `p_i^0`：

\[
r_i^{new}=r_i^{old}+(1-p_i^0)\,\delta m_i,
\qquad x_i^{new}=x_i+\gamma\,\operatorname{Bound}_{0.1\|x_i\|}\bigl(W_o r_i^{new}\bigr).
\]

内容修正绕过 shared/private 选择的 Jacobian；仍沿用原 null 专家的抑制作用，不声称 null 已学会可靠的拒绝判定。新修正不使用 learnable attention-null 的 Value。即使3路专家保持近固定，只要非null质量不接近0，模板相对证据仍能通过 `δm` 改变实际写回内容。

原 gamma=0 的初始化仍提供输出恒等边界；未来公共参数必须从同一初始 state 克隆。不能再只比较相同 seed 下分别构造的两个模型。

### 7.5 设计与问题一一对应

| 当前可审计缺口 | 本设计对应项 | 预期信号 |
|---|---|---|
| search相似性没有模板目标身份 | 首帧框软覆盖 `w̃` | 正确mask比等面积移位mask更有目标特异性 |
| competitor可能是同目标其他部位 | 目标尺度非邻域参考，且不赋负标签 | 同目标参考污染降低；异常尺度下不强行做判断 |
| 竞争信息只改变3路权重 | `(Ac−A0)V`直接进入实际消息 | 即使固定原router，改变竞争参考仍影响内容 |
| 只看局部绝对相似 | 同一模板片段的相对支持 `S−b` | 普遍响应片段被弱化，具区分度片段占比提高 |
| 幅度变化可能被误称内容重构 | 零和来源重分配 + 方向/可分性实测 | 收益应超过等范数纯缩放对照 |

### 7.6 可行性、复杂度和风险

可复用现有 Q/K/V、output、gamma，新增可学习参数可仅为两个λ标量。参数更少不等于表达力更弱：改变的是每个 `(search位置, template片段)` 的来源分配。但小参数量也不意味着低 FLOPs 或一定好训。

匹配矩阵仍为每 head 256×64；`(Ac−A0)V`只需一次额外矩阵乘。非邻域 logmeanexp 若朴素展开会生成 `[B,h,256,256,64]`，有明显内存风险；实现时应逐模板/搜索块分块归约，或用矩形窗口求和优化，并用FP32稳定计算。窗口求和中的大数相减需要稳定fallback。**未实测前不承诺保持57.54 FPS。**若实现成本无法控制，应先使用全局普遍性参考的简化消融，并明确它没有排除同目标片段，不能暗中替换主定义。

主要风险：首帧框包含背景、目标形变超出几何先验、完全相似的干扰物共享全部模板片段、遮挡时所有相似度都不可信、MSHA融合本身已污染Value、来源softmax也可能饱和。尤其当真目标与干扰物对所有j具有相同 `S` 时，此方法无法创造新的身份信息；不宣称解决全遮挡恢复或目标完全出crop后的搜索。

这是从“目标身份 + 相对特异性 + 内容路径”推导出的机制设计，不是仅因公式更长就成立。数学上 `λd`仍是来源 attention 的条件 bias；**不能把它包装成从未有人做过的新注意力原理**。可发表性取决于这个完整组合的独立实证和与相近方法的诚实比较。

## 8. 不重走历史失败的边界

| 既有资产 | 能支持的限制 | 本方案应如何区别 |
|---|---|---|
| MSHA differential fixed28 | severe/good 的 self-cross重合及message cosine基本相同，不支持统一全局相减 | 不做全局跨模态相减，使用目标模板片段及候选相对支持 |
| early Value reconstruction fixed46 | 原比较混合checkpoint；同checkpoint开关影响很小 | 不用旧跨checkpoint正信号证明内容重构有效；新内容必须做同状态干预 |
| early relation bias quick | 短训未稳定收益，且缺少真正matched parent | 数学上本方案也含bias，必须与相同目标mask的普通来源分配及内容位置对照，不能改个名称当新路线 |
| C5 template-template Sinkhorn | 历史B3/S1、64×64、统一质量约束；并非M1 search-template证据 | 不重复统一双随机匹配，不把旧未过阈值解释成所有竞争归一化无效 |
| CSTNet / NLformer / WeightFormer源码参考 | 空间融合/通道统计/动态权重的通用设计可参考 | 不复制完整模块并宣称问题自然解决；本轮没有新增移植 |

跨领域可借鉴的原则是信息检索中的“局部匹配要结合证据普遍性”及残差内容重分配。它们不是本项目独创。相近 RGB-T 工作、候选消除、背景抑制、对比匹配和双归一化注意力均需要在投稿前继续查重；当前不能声称“首次目标条件融合”，也不能仅靠场景前缀区分方法。

## 10. 能写进论文的链条与目前缺口

**可写的现象事实**：M1已有失败链条以及本组244序列离线统计均表明，存在目标几何仍在crop内而定位失配、随后部分出界的窗口。当前STSER把竞争信息限制在专家路由，且训练采样显示路由早期近确定化。

**对应设计**：以首帧目标区域锚定模板证据，按同一模板片段的候选相对支持重分配Value来源，并把差值直接写入STSER内容路径。

**需要补齐的实证中介**：正确目标/竞争语义 → 来源分布和消息方向改变 → 同crop下目标/干扰区分改善 → 框内错误发生率/持续时间下降 → 相同训练合同下最终指标提升。CENTER输出只是这条链的一个观察点，不是本轮创新对象。

如果只得到最终微小涨点而中介和语义干预不成立，应把结果写为经验性融合改进，不能声称已解决特定原因；如果中介成立而全量仍无增益，应报告局部机制有效但系统收益未建立。当前结论为：**已排除本组错误初始化起点；已观察路由饱和及竞争内容路径缺口；尚未区分全部掉点原因；支持下一步单变量检验，不支持直接宣称完整因果闭环或承诺+0.5。**
