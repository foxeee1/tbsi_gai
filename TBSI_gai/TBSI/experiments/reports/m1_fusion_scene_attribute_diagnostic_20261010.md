# M1 融合失效的场景与属性细分诊断（2026-10-10）

## 结论先行

这次只读诊断把问题收窄为：**M1 的严重场景同时有中心选择失败和框重叠失败；搜索特征在失配发生前已变得难以读出，当前证据不支持把首因定为全局融合算子把信息抹掉。融合输出仍有部分可解码信息，但实际 CENTER 峰与目标位置没有稳定对齐。**

按属性看，低分辨率/小目标的困难更偏向尺度归一化定位与高阈值重叠；高运动组 PR 差距不稳，但 OP75 明显下降；SA/TC 同时压低 PR、Success 和 OP50/75，更像身份歧义/干扰峰与框定位耦合。LI 是较温和且样本较小的风险富集；BC 组在这些指标上的区间跨零。它们只能描述风险切片，不能把属性解释成融合因果。

当前优先怀疑顺序：

1. **失败前的最终 search 表征/模板条件化不够稳定**，尤其是目标仍在 crop 内但 GT 周围与干扰位置难以分开的帧。
2. **CENTER 峰值排序与框解码之间的定位接口**：目标位置分数随成功变化，但最高响应强度在低分辨率、SA/TC 序列里较少跟踪 IoU；GT 格点下 offset/size 仍有误差。
3. **闭环状态反馈**：最初偏差后，预测框改变下一帧 crop，许多长失败随后 crop-out。
4. **搜索融合本身或模态可靠性失衡**：目前未获直接支持。两路 cross-message 范数与定位的关系接近零；没有目标级 RGB/TIR 质量、配准偏移或单模态可用性真值。

这不是“RGB-T 融合无问题”的证明。M1 full-244 梯度/信息流来自当前工作树重放，和保护归档逐帧不等价；full-244 只用于描述归档 PR/SR 与场景分布，不把它和重放帧响应逐帧拼接。

## 2. 融合接口证据

### 模板 MHSA：路径活着，不等于消息有益

full-244 当前工作树 replay 中，loc3/6/9 的 RGB/TIR 输入输出、QKV/Proj、`tbsi_fuse_search` 输入输出等 24 个梯度范数列，在 7,807/7,807 个采样有效帧均非零。它排除的是“梯度路径整体断开”，不表示训练更新健康或消息贡献正确。

按序列相关汇总，loc9 entropy 与 IoU 的中位 Spearman 为 -0.086，95% bootstrap 区间 `[-0.122,-0.002]`，效应弱。loc9 TIR 与 RGB cross-message 范数和 IoU 的中位相关分别为 +0.0067、+0.0199，区间 `[-0.039,+0.070]`、`[-0.063,+0.066]`，均跨零。QKV 梯度范数和 IoU 中位相关 -0.425，RGB/TIR search 输入梯度相关 -0.437/-0.448；较差定位更敏感于损失是合理的反向因果解释，不能读作 MHSA 欠训或应加大某模态权重。

**场景切片：**full-244 分层里，低 AUC、LR、SA、TC、LI 和小目标/高运动组的 RGB/TIR cross-message 相关没有稳定一致的方向。尤其低 AUC+LR 的 message 相关为弱正而不是明显负值，不能据此推“该压低 TIR/RGB”。熵和 IoU 负相关在小目标+高运动组更明显（序列中位 -0.296，相对组外约 -0.242），但该组仅 25 条且 attention entropy 受目标大小、运动和 crop 状态共同影响，只是探索性歧义信号。

### 最终 search 表征与融合：输入先难读，融合后未见一致二次坍塌

train-side held-out probe 的 16 个失配前驱/起点显示：匹配正常帧时 RGB/TIR/concat/fused 的 target-background margin 中位分别为 `+7.69/-1.12/+13.43/+10.99`；失配前驱时为 `-11.65/-3.05/-15.91/-4.38`；严重起点为 `-15.43/-8.49/-18.22/-6.04`。严重起点 fused margin 数值比 concat 少负约 12.18，但四种 probe 输入维数不同，不能作等容量因果比较。绝对上，两路输入与融合输出仍普遍是负 margin。

更重要的空间读出：严重起点 GT 区域成为 probe 最高响应区域的比例，RGB/TIR/concat/fused 只有 `6.2%/12.5%/6.2%/6.2%`；fused probe 峰到 GT 中心中位 `4.95` 个 token，目标背景 margin 仍为 `-6.04`。这说明“margin 数字改善”不等于目标峰被恢复。失配在融合前已存在；融合后并未在该 probe 上一致更坏，但真实 CENTER readout 仍没有稳定定位目标。

这批 72 个 train-side 序列、104 个固定帧（其中 16 条序列各有前驱和严重起点）是当前工作树 replay。GT 定义网格和线性 probe 测可解码性，不等价于模型原生 CENTER head 的决策；concat 输入维数不同，不支持融合有益或有害的因果断言。该观察的机制归因等级是 **“融合不是已证实首个坍塌接口；最后 search 表征对目标/干扰的可读性不足，且读出未解决”**，不是“融合无责”。

### score 与框回归：峰值置信度和定位一致性不是一回事

full-244 当前 replay 的 244 条序列中，GT-cell response 与 IoU 的序列相关中位 +0.241（95% CI `[+0.173,+0.311]`，67.2% 序列为正）；peak response 与 IoU 中位 +0.439（CI `[+0.408,+0.483]`，90.6% 为正）。这表明 head 输出随定位质量变化，但不是局部证据存在的证明。

按归档低 AUC 分组，GT-cell response-IoU 相关中位 +0.644，相比 AUC≥40 的 +0.087 高 +0.557；而 peak-response-IoU 相关仅 +0.346，相比 +0.453 低 0.107。低 AUC+LR、SA、TC 组 GT-cell 相关分别 +0.652/+0.613/+0.630，peak-response 相关分别 +0.211/+0.334/+0.320。谨慎的解释是：这些序列中“GT 位置分数的起伏”和成功程度有关，但当前最高峰的强度/排序较少表示正确定位质量，符合峰竞争或置信度校准问题的假设；它不证明 heatmap focal、Hann 或局部窗口是根因。

GT 选格反事实进一步约束：20 条固定状态事件中，指定 GT cell 相比实际 Hann peak 让 16 条同时改善中心误差与 IoU；但 GT cell 解码后中心误差中位仍 9.25 px，只有 3/20 低于 5 px。故存在两个可分离误差项：选格错误，以及同一 `size/offset` map 的回归/尺度读出误差。Strip 仅改 score 分支，不可能单独修复后者。

## 4. 对 LCGA 与 Strip 的融合归因

- **LCGA 是 pre-fusion 双路局部变换。** 它的负结果不能归因于融合层直接把它的局部信息“冲掉”：联合续训中上游 search/backbone 也更新，存在训练分布漂移；冻结 M1 合同在不同 dev 上仍未显示中心收益。其失败只否定当前算子、注入点/合同及预算的联合候选，不否定局部表征方向。更具体地说，已有接口 probe 显示失败输入特征早已弱，若给每路加局部精化而没有稳定目标-负峰监督，可能在已有噪声上重排而非恢复目标。
- **Strip 是 post-fusion score-only 调制。** 它没有改变 pre-fusion/fused backbone 表征，因此不能作为跨模态融合可靠性模块来评价；这轮实际格点完全未变。它的优化对象与定位决策存在不匹配：focal 能塑造 GT 热图，但硬 argmax 让框回归 loss 不教它战胜困难负峰。即便改损失，GT-cell oracle 中残余框误差和不稳定特征读出仍是限制，所以目前不批准只加 ranking loss。
- **共同点不是模块没接上。** 两条路径均有效、能改变某些 tensor/prediction，但没有证明所改变量对应主要错误。应先定位“哪一stage/哪一输出量首次对不上”，再选方法：表示缺失对应高分辨率/局部特征；两模态相反质量才对应可靠性门控；位置对应错误才对应对齐/deformable；目标 evidence 稳定但 score 选错对应 head/ranking；GT score 对但 size/offset 错对应框回归适配。

## 5. 下一道诊断门（不训练）

下一步不运行新模块，而是在**未用于选候选的 LasHeR train-side 序列**预先冻结约 24–32 条序列、每条一个可见失配起点和一个匹配正常帧，至少覆盖小目标/高运动、SA/TC、LI/BC。若标注审阅确认目标不可见，另作为“不可恢复”桶，不混入局部辨识指标。

同一模板、真实上一帧浮点状态、同一个 search crop 下只采集：

1. backbone 浅层高分辨率特征、两路最终 search token、`tbsi_fuse_search` 输入/输出；各自用序列留出 probe 测 GT 邻域与 hard-negative 的 margin、峰距和 top-1 命中率。
2. 当前原生 CENTER raw score 与 Hann score 的 GT-cell、top1/top2、最强 GT 外 hard negative；用真实 size/offset 同时解码 raw peak、Hann peak、GT cell，分开中心与尺度误差。
3. 两模态质量与目标区域对应偏移；单模态轻度 dropout/attenuation 只在固定 crop 做因果方向探针，不能用它直接评估闭环泛化。
4. 前驱/起点与正常帧配对后比较；序列为 bootstrap 单位。不以 test-244 分层选择模块或阈值。

**分流阈值：**若浅层 probe 尚不能区分 GT/困难负峰，局部窗口不是首选，优先查 crop/模板/可见性；若浅层可读而最终 per-modality/fused 可读性坍塌，才开一个高分辨率保留或局部表征方向；若单路分别可读、融合后稳定变差且跨多序列，才验证模态可靠性/空间对齐；若 fused probe 可读但真实 CENTER peak 选错，才研究 head 读出/排序；若 GT-cell 解码仍系统性偏框，则改查 size/offset 而非 score-only Strip。每次只允许一项方法改动。

当前工作树重放的 244 序列预测与保护归档有 82,219/219,048 帧坐标差超过 2 px，因此上述下一道门应被称为**当前 M1 权重/config 下的机制诊断**，不能称严格复现 M1 原训练代码；如需把结论外推到登记锚点，先恢复/冻结原始 tracker 源码快照并过逐帧 parity。
