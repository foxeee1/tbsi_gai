# C1-C4 RPP-v2 quick experiment report

## Contract

- Parent: B3 dense V2 fusion. Canonical baseline was not modified.
- Train: frozen `RPP_LasHeR_train` sequence manifest, 10752 samples/epoch, 3 epochs.
- Test: frozen 60-sequence `rpp_lasher_test` manifest, FP32 tracker, serial execution.
- Quick-test deviation: each sequence was truncated to at most 80 frames because full serial testing was prohibitively slow. These metrics are screening-only and are not comparable to full-sequence B3/S1 numbers.
- Seeds: repository default training seed. This is not the required multi-seed final confirmation.

## C1 compatibility analysis

C1 produced 28,440 valid rows over 60 sequences. The diagnostic used the S1 epoch-3 checkpoint with the dense V2 config because no independently saved B3 dense checkpoint was available; this is explicitly a proxy diagnostic.

- Global target-pair attention purity: `0.0617`.
- Global top-10 target-pair purity: `0.3546`.
- Layer 3 top-10 purity: `0.166` RGB2TIR, `0.181` TIR2RGB.
- Layer 9 top-10 purity: `0.528` RGB2TIR, `0.551` TIR2RGB.

The signal becomes more target-local at later TBSI layers, but early cross-modal attention is largely target-irrelevant. This supports diagnosing a compatibility/distribution problem, but does not establish that the tested biases solve it.

## Stability and artifacts

C2, C3, and C4 completed with finite logged losses and saved epoch-3 checkpoints. Each training log contains the existing diagnostic zero-gradient notices; C2 and C3 also contain one non-finite gradient-norm warning. Treat all candidates as unstable/inconclusive rather than successful.
